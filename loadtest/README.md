# Навантажувальне тестування (`loadtest/`)

## Опис сценарію (`load_test.js`)
Тест написаний для інструменту **k6** і моделює поведінку користувачів із профілем навантаження **read-heavy** (10% операцій запису та 90% операцій читання).

У межах однієї ітерації кожен віртуальний користувач (VU) виконує:
1. **1 запис:** `POST /users` — створення нового користувача з унікальними `username` та `email`.
2. **9 читань:**
   - 5 запитів `GET /users` (отримання повного списку користувачів із бази даних або кешу);
   - 4 запити `GET /users/:id` (отримання профілю щойно створеного користувача за ідентифікатором).
3. Пауза `sleep(0.2)` між ітераціями.

### Профіль віртуальних користувачів (9 хв 30 с)
- **Фаза 1 (Ramp-up, 2m30s):** плавне зростання з `0` до `50` VU.
- **Фаза 2 (Steady state, 5m):** утримання пікового навантаження `50` VU.
- **Фаза 3 (Ramp-down, 2m):** плавне зниження з `50` до `0` VU.

## Встановлення та запуск

1. Встановити `k6` (macOS):
   ```bash
   brew install k6

2. Запустити повний тест проти розгорнутого Application Load Balancer:
    ```bash
   k6 run loadtest/load_test.js

3. Або передати власну адресу балансувальника через змінну середовища:
